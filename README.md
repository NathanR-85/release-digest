# Release Digest

What changed in Claude Code since you last looked.

The built-in `/release-notes` shows everything every time. This one remembers where you left off and only shows what's new, sorted into Features and Bugs.

## Usage

```
/release-digest          # since you last ran it
/release-digest 7        # last 7 days
/release-digest --reset  # mark all as seen
```

## Install

Point Claude Code at this repo. Say user-level for everywhere, or project-level for just one project.
